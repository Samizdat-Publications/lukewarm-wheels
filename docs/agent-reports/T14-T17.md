## T14 — `tools/build.mjs`

```
node tools/build.mjs        # -> dist/index.html
```

- Reads `index.html`, finds the `<!-- HW:SCRIPTS ... -->` / `<!-- /HW:SCRIPTS -->` markers and
  replaces everything between them with the 13 files listed in `src/manifest.json`, in order,
  each wrapped in its own `<script data-hw-file="src/…">` tag (the attribute makes the single
  file readable and greppable; it is not a URL).
- A literal `</script` in any source is escaped to `<\/script` (identical to the JS parser,
  inert to the HTML parser). No source currently contains one, but the guard is there.
- Nothing else is inlined. The importmap and the `<script type="module">` loader are copied
  verbatim — their imports are `https://cdn.jsdelivr.net/npm/…`, which the Artifact CSP allows
  (`docs/DEPENDENCIES.md`). There are no external stylesheets, images or fetches, so the output
  is CSP-safe as-is.
- Prints per-file and total size. Exits 1 if `index.html` is unreadable or missing a marker,
  if `src/manifest.json` lists a file that does not exist, or if the result still contains a
  real `src="src/…"` attribute.

## T17 — `tools/selftest.html`

server and prints that URL — the checks need the real browser + wasm Rapier, so there is no
headless Node runner). Same importmap and module loader as `index.html`; the 13 manifest scripts
are listed explicitly in the same order. Immediately after `90-main.js` the page sets
