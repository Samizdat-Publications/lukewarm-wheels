# T13 — control panel UI (`src/60-ui.js`)

Opus subagent, 2026-09-08. Replaces the stub; `90-main.js` now calls `HW.ui.init()`
and the text HUD (`#hud`) is hidden.

## API
`HW.ui = { init(), select(car), selected, showToast(msg), armed, syncChips(), rebuild() }`.
No markup in `index.html`: the file injects a `<style>` block and builds the whole
panel from JS into `document.body` (`#hwui` > `aside.hwp`, 300 px, collapsible via the
`«` button / `☰` tab). System fonts and inline SVG only — artifact-CSP safe.

## What is in the panel
1. **Header + booster switch** — red slide switch calling `HW.sim.toggleSwitch()`,
   reflected from both `HW.bus.on('switch')` and `telemetry.elec.on`.
2. **Run buttons** — Line up all five / Reset / Nudge (selected car, else
   `HW.sim.nudgeStalled()`) / Lift all.
3. **Car chips** — colour swatch from `entry.color`, name, lap count.
   Click a *placed* car → select + `car.lift()`. Click a *lifted* car → select and arm
   placement; the next click on `#view` converts to NDC, calls `HW.render.pickLane(x, y)`
   and `HW.sim.placeCar(car, hit.path, hit.s, 0)`. Esc cancels; a drag (>5 px between
   pointerdown and click) is treated as an orbit, not a placement. Double-click a chip →
   `car.spawnAtGate(HW.sim.track.lineUp[i])`. A hint line names the current mode.
4. **Gauges** — six inline-SVG 240° arcs with needles (battery V 0–6.5, motor A 0–4,
   motor rpm 0–16000, foam surface cm/s 0–600, selected-car cm/s 0–600, 1:64 km/h 0–1400)
   plus crash and total-lap readouts. Updated on `telemetry` (~20 Hz) by mutating three
   attributes per gauge — no DOM rebuilds.
5. **Event log** — last 6 of `crash` / `stall` / `lap` / `offtrack`
   ("Ford GT-90 hit Porsche 959 at 212 cm/s", "Chevy 1500 stalled", "Aeroflash lap 2").
6. **Camera row** — a button per `HW.render.cameraNames` (currently overview / crash /
   chase / booster / gears) calling `setCamera`, plus an X-ray checkbox calling
   `HW.render.xray(bool)`. Rebuilt on `sim-created` / `booted`; degrades to a hint line
   when `HW.render` is still the stub. Every `HW.render` call is guarded.
7. **Tuning drawer** (collapsed by default) — 25 sliders bound live to `HW.config`,
   grouped Foam / Motor-battery / Cars / Track geometry. Ranges: 0.25×–4× for stiffness
   and torque constants, 0–1 for fractions, ±40 % for geometry. 12 keys carry a
   `REBUILD` badge that lights when touched (`battUsedFrac`, `frictionSlip`,
   `sideFriction`, `comDrop` and all eight track keys). **Rebuild track** calls
   `HW.sim.create()` + `HW.render.rebuild()` when that exists, else serialises the
   non-default config into `location.hash` (`#cfg=<json>`) and reloads; the hash is
   parsed back into `HW.config` at script-load time, before `hw:libs-ready`.
   **Defaults** calls `HW.config.reset()` and refreshes every slider.
8. **Footer** — the 90-main keyboard shortcuts. Those handlers are untouched and still
   skip INPUT/TEXTAREA, so sliders never lose keys to them; the UI's own Escape handler
   does the same check.

## Verified in the browser (http://localhost:8765/)
- Zero console errors (only three-r185 `PCFSoftShadowMap` deprecation warnings from the
  renderer and a favicon 404).
- Line up + switch ON: gauges move (6.13→6.27 V, 0.302→0.153 A, 12267→12908 rpm,
  511→538 cm/s surface, selected-car speed and scale km/h track it); `lap`/`stall`
  events land in the log; chip lap counts increment.
- Placement: chip click armed Aeroflash, `pickLane(-0.6, -0.5)` hit circuit NS at
  s = 190.7, the synthesised canvas click placed the car on NS (lifted → false) and
  disarmed with a toast.
- X-ray checkbox flipped `HW.render.xrayOn`; camera buttons list all five presets.
- Tuning: `foamMu` slider applied live (1.3994), a track slider lit its REBUILD badge,
  and `?…#cfg={"foamMu":1.55,"lobeLift":7.25}` restored both values into `HW.config` and
  into the slider readouts at load — the reload path of Rebuild track round-trips.
- Screenshots: `docs/screenshots/T13-ui.png` (panel top, booster ON, live gauges) and
  `docs/screenshots/T13-tuning.png` (tuning drawer open, rebuild badges, footer).
